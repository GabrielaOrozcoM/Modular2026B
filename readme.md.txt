Configuración del control de versiones: Inicializa el repositorio en GitHub aplicando Git Flow (ramas main para código estable, develop para integración y ramas feature/ por desarrollador).  Infraestructura de nube: Registra el proyecto en Firebase Console, habilita Firebase Auth y genera las credenciales de la API de Google Maps.  Definición de modelos de datos: Diseñen en conjunto el esquema JSON de las colecciones de Cloud Firestore (users, food_logs, vendors, reviews). Esto permitirá que el frontend use datos de prueba (mock data) mientras el backend construye los servicios.
